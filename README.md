# hammadkhaliqhere.github.io

My personal portfolio site.

**Live → [hammadkhaliqhere.github.io](https://hammadkhaliqhere.github.io)**

## About this site

A single self-contained page — no build step, no framework, no dependencies to install.
Everything ships in one `index.html`: the markup, the styles, and the portrait as an
embedded data URI.

**Built with:** HTML5, CSS3 (custom properties, grid, flexbox), Google Fonts (Bricolage
Grotesque, IBM Plex Sans, IBM Plex Mono).

**Notable bits**

- Light and dark palettes defined as CSS custom properties, following the visitor's system
  theme and any explicit theme choice
- Responsive down to ~400px — the fact grid, project rows and background entries all
  collapse to a single column on a phone
- No JavaScript at all

## What's on it

Who I am, what I am available for, the client sites I have worked on with my exact role on
each, the tools I use, and how to reach me.
